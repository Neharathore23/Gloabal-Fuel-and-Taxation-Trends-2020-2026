JSON API

All endpoints are read-only GET. Filters are query parameters: date_from, date_to (YYYY-MM), and comma-separated country (ISO-3 codes), region, fuel, income. Invalid values return HTTP 400 with {"error": ...}.

/api/optionsFilter choices and date range
/api/kpisKPI values for the selection (empty: true when nothing matches)
/api/chart/<name>Plotly figure JSON. Options: by, n, horizon
/api/data/<name>Tables: price_stats (by=region|fuel_type|income_group), country_table
/api/chartsList of available charts
/api/qualityData quality report
/healthzLiveness and database status

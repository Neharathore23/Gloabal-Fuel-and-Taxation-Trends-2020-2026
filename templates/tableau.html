Steps that need Tableau Desktop / Public
  1. Connect to the flat CSV, or to data/fuel_analytics.db via an SQLite ODBC/JDBC driver.
  2. Create the calculated fields in tableau/calculated_fields.md.
  3. Build the sheets, dashboards and five-scene story from the specifications in tableau/.
  4. Publish to Tableau Public (the data become public) and copy the “Share → Embed” URL.
  5. Set TABLEAU_EMBED_URL and restart this app.

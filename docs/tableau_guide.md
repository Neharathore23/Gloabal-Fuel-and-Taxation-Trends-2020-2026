# Tableau guide

Full specifications live in the `tableau/` folder:
* `connection_guide.md` - CSV / relationships / PostgreSQL / Tableau Public publishing / Flask embed
* `calculated_fields.md` - 18 calculated fields + 3 parameters
* `dashboard_specification.md` - 13 worksheets, 5 dashboards, 5 filters, 6 actions
* `story_specification.md` - 6 story scenes (5 required + 1 optional)

**No .twb/.twbx is included** and none was validated in Tableau. Manual in Tableau: connect, create fields/parameters, build sheets, dashboards, story, publish, copy the share URL into `TABLEAU_EMBED_URL`.
